# Homework_2 — Многопроцессность

## Задание 1
Создайте программу, которая параллельно вычисляет квадраты чисел от 1 до 10 и выводит результаты в консоль.

## Задание 2
Напишите программу, которая использует 3 процесса для поиска максимального значения в трех разных массивах случайных чисел (каждый массив размером 100 элементов).

## Задание 3
Создайте программу, где родительский процесс создает два дочерних процесса:
- один читает содержимое текстового файла,
- другой записывает в новый файл перевернутые строки из исходного файла.

## Задание 4
Реализуйте параллельное вычисление суммы элементов большого списка (минимум 1000 элементов), разделив список между несколькими процессами и объединив результаты.
